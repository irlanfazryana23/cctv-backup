# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Contact the
repository owner through GitHub with a private report and include:

- affected version or commit;
- a concise description of the impact;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation.

Remove passwords, DVR serial IDs, IP addresses, usernames and local paths from
all reports. Do not send private recordings or vendor binaries.

Security fixes will be coordinated privately before public disclosure when
possible.
